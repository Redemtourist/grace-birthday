# 🎂 Happy Birthday Grace ❤️

A beautiful interactive birthday website built with HTML, CSS and JavaScript.

## Features

- ❤️ Romantic welcome screen
- 🎁 Gift opening
- 📸 Animated photo gallery
- 💌 Typewriter birthday letter
- 🎂 Interactive birthday cake
- 🎆 Fireworks
- ❤️ Floating hearts
- 🎵 Background music
- 📱 Mobile responsive

## Folder Structure

Birthday-Surprise/

images/

# 🎂 Happy Birthday, Grace!

## 📦 What's Inside

- **birthday-grace.html** — The main webpage
- **image_*.png** — 9 beautiful photos (optimized for mobile)
- **DEPLOYMENT_GUIDE.md** — Full step-by-step instructions

## 🚀 Quick Start (3 Steps)

1. **Download** all files from this folder
2. **Choose a hosting option** (see DEPLOYMENT_GUIDE.md):
   - GitHub Pages (free, reliable) ⭐ Recommended
   - Netlify (simplest)
   - Vercel (fastest)
3. **Upload files** to your chosen platform (takes 5 minutes)
4. **Send the link** to Grace!
